# SOME TEAMS! 

This repository contains the 'Some Teams' project of Jonne Covers, WU26.

## The project

SOME TEAMS shows a website built with PHP, HTML and CSS. The site portrays a handful of teams of the Women's UEFA Cup, that is held this autumn. The PHP code loops through data about the teams, creating a small information card for each (hehe).

The information displayed on the card contains: the name of the team, the home-town of the team, the logo and the position they are at in the league (on October 15th). Once teams start dropping out of the competition, the author has a simple feature hidden in the data that will make the dropping out visible in the cards. Stay tuned.
If one is interested in more, they can click on the card to visit the UEFA-page linked to the team.

Is one more interested in learning about the author, they can click on the 'ABOUT' button in the header, to navigate to a page with a small bit of information about the author.
